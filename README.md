# AI-Powered Customer Churn Predictor & Retention Dashboard 🔮

An end-to-end Machine Learning web application that predicts customer churn risk using a Random Forest Classifier and provides automated retention strategies.

## 🤖 Features
- **Machine Learning Classification:** Trained on customer tenure, contract types, monthly charges, and tech support usage.
- **Real-Time Prediction:** Interactive Streamlit dashboard allowing users to adjust customer parameters live.
- **Actionable Insights:** Generates tailored retention recommendations based on calculated risk probabilities.
- **Model Explainability:** Displays feature importances to show key drivers behind churn.
